# Krishna Paliwal - Portfolio Website

A modern, responsive and accessible personal portfolio website built using HTML, CSS and JavaScript.

## Features

- Responsive navigation
- Hero section
- About section
- Skills section
- Services section
- Projects section
- Resume download
- Contact form with validation
- Dark mode
- Smooth scrolling
- Mobile hamburger menu
- Responsive design for mobile, tablet and desktop
- Accessibility-friendly structure
- SEO metadata
- GitHub and LinkedIn links

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Grid
- Media Queries
- Git
- GitHub
- Visual Studio Code
